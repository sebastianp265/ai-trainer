# AI Trainer

A personal Android app that acts as an AI personal trainer. It collects gym workouts, daily calorie burn and body weight (Polar), calorie intake (Fitatu via Health Connect) and your preferences, and will use the Claude API to generate and adjust a flexible training and nutrition plan. All data stays on the device.
